# GianaOS Model Evidence Catalog

This package holds typed, source-only route evidence for Giana CoWork Preview. It does not register an LLM provider, publish a model in the selector, change a default, start a model process, or admit a route.

## Authorities

Identity, sessions, memory, workers, approvals, credentials and audit remain with the canonical GianaOS/GDM front door. R5300 supplies deployment evidence through the existing model lifecycle and Server Manager ownership boundary. This package does not create another registry, router or lifecycle controller.

## Six-model packet

The current packet contains four GLM 5.3 records and two DeepSeek V4 Flash Vision records. All six are hash-bound to the AI StudioTech handoff, assembly receipt, independent validation and selection index. Five have recorded R5300-compatible runtimes. The MLX record is audit-only and disabled for R5300. The GLM GGUF Q6_K record remains held from agentic tool routing because native tool-call objects failed three of three tests.

Recorded test success is not live health. Every record remains `BLOCKED`, `sourceOnly`, `routeAdmission: false` and `productionGreen: false`. A model appears in the existing UI selector only after the canonical owner admits it and an existing provider adapter advertises the live route.

## Selection

`verifySelectionEvidence()` delegates detached receipt validation to a canonical authority and mints an in-process capability bound to the exact immutable descriptor. `materializeSelection()` rejects plain or mismatched evidence. No UI flag can bypass this boundary.

Rollback is owned by the existing model lifecycle controller. It restores the exact captured previous healthy resident route; this catalog does not assume Qwen, GLM or any other model is the rollback target.

## Model Experience

### Held route evidence

#### What the model sees

Nothing directly from `@grinviro/dsh-gianaos-catalog`. The catalog adds no prompt, tool, provider response or model-visible metadata. A model sees ordinary GCP context only after a separate admitted provider route is selected.

#### Token effect

Zero tokens while records remain held. Admission elsewhere does not make these evidence objects part of the request.

#### KV Cache effect

None. The catalog neither rewrites conversation history nor changes model input. A later provider switch may change cache reuse according to that provider and the lifecycle controller, outside this package.

## Known Limitations and Deferred Work

- **No live provider binding** - current route admission and a deployed Server Manager binding are still required.
- **No selector publication** - held records deliberately remain absent from the live model selector.
- **No runtime currentness claim** - hash-bound canary evidence records past tests, not present listener health.
