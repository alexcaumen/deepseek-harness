# Agent Note: 受治理的本地模型生命周期

Status: implemented

[English](2026-09-04-governed-local-model-lifecycle.md) | 中文

## Problem

本地模型推理可能需要容量准入、排空请求、停止一个运行时、启动另一个运行时、检查健康状态与能力，并在失败后恢复先前模型。如果在用户只是选择模型时执行这些工作，可能会在另一项推理仍持有资源时将其驱逐。复用语音计算控制器还会把本地模型生命周期与独立的 STT 和 TTS 路由混合起来。

控制器必须保留治理身份与请求顺序，同时不能成为第二个模型选择权威。它也不能把超时的主机操作、未经验证的清理或失败的审计写入当作物理资源状态已知。

## Decision

`@deepseek-ai/dsh-model-lifecycle` 管理一个串行化的进程内大模型槽位。LLM 服务仍是唯一的提供方／模型选择权威。安装的唯一 `ModelLifecycleAuthority` 提供粗粒度提供方分类、受治理路由与执行作用域解析，以及已净化审计持久化；`register()` 把不可变的已准入路由副本绑定到主机专用驱动。提供方分类发生在本地 FIFO 之前。`UNMANAGED_EXTERNAL` 选择获得一个惰性租约且不进入该 FIFO，`GOVERNED_LOCAL` 选择则在异步权威解析之前进入 FIFO，因此更快完成的后续解析不能越过较早请求。

请求到达 FIFO 队首后，运行时先拒绝已受污染的槽位，再请求权威组件解析请求。受治理结果必须在任何驱动操作之前，与已注册路由的 id、提供方／模型对、准入摘要、修订摘要、`AVAILABLE` 状态和已准入推理强度匹配。执行作用域包含非空的 `workId`、`principalId`、`tenantId` 和 `sessionId`。运行时按此顺序使用 NUL 分隔这四个值，重新计算规范的小写 SHA-256 摘要，拒绝摘要不匹配或请求会话不匹配，并为该事务冻结解析后的作用域副本。`HELD`、不一致、未注册和不可用的路由都在资源操作前失败。

Automatic 目标选择只考虑已准入路由 manifest（元数据清单）声明的目标，固定顺序为 R5300、PRDG、RAM/CPU。只有路由同时声明 `ram-cpu` 并设置 `allowRamCpuOffload` 时才会考虑 RAM/CPU；每个候选都必须通过容量预检。明确的不可用决定会让 Automatic 继续检查下一个已准入候选，而预检错误或超时会终止请求。手动 `r5300` 或 `prdg` 意图只探测该目标，并返回 `MANUAL_TARGET_UNAVAILABLE`，不会回退。

目标预检成功后，运行时捕获预状态。真实切换随后依次排空先前路由、停止该路由、验证其已停止、启动所选目标、验证健康状态并执行能力探测。运行时在适配器迭代开始前持久化 `READY` 审计记录。复用同一已注册路由和目标时，会执行预检、预状态捕获与健康验证，但不会停止、启动或执行能力探测。受管理租约贯穿完整异步 `llm/stream`；`finally` 尝试记录 `RELEASED` 并释放 FIFO 位置，因此另一项受管理请求不能在推理中途卸载活动模型。排队期间取消的请求会在轮到其锁位置时释放该位置，不会使后续请求饥饿。

每次主机驱动调用都会收到各自的绝对 `deadlineAt`，以及受 `stageTimeoutMs` 约束且由运行时拥有的取消信号。成功的 `prestate`、`preflight`、`drain`、`stop`、`verify-stopped`、`start`、`health` 和 `probe` 结果携带结构化 `ModelLifecycleStageReceipt`。运行时要求每份回执包含预期阶段、路由 id、目标、修订摘要、作用域摘要和事务摘要，以及一个小写 SHA-256 回执摘要。父级取消会取消受约束信号；截止时间到期会取消该信号并返回 `STAGE_TIMEOUT`，即使驱动尚未结算。

在尝试停止或启动之后发生非超时失败时，运行时会先停止目标并验证其已停止；如果先前路由存在，再重启并验证该路由。完成验证的恢复会保留先前资源，并报告已回滚或已拒绝结果。任何阶段超时都会把槽位置为 `TAINTED`；目标清理无法通过 `verify-stopped` 证明已停止、无法恢复并验证先前路由，或权威组件的审计持久化失败，也会污染槽位。释放已完成推理时的审计失败不会使已完成输出失效，但仍会取消空闲卸载，并使后续所有受治理本地获取都以 `RUNTIME_TAINTED` 封闭失败。运行时不提供推测性继续执行或自动解除污染的路径；必须进行主机调和或有序重启运行时。

成功释放后，`minimumDwellMs` 与 `idleUnloadMs` 可以在同一 FIFO 下安排空闲卸载。卸载会捕获预状态、停止活动路由、验证其已停止，并记录 `IDLE_UNLOADED`；将 `idleUnloadMs` 设为零会禁用计时器。卸载超时，或卸载失败后无法通过恢复重新建立已验证状态，也会使槽位保持 `TAINTED`。

该包导出权威、路由、作用域、回执、驱动和运行时接口，但不提供具体治理权威、已准入路由注册或主机驱动。仅加载该包不会注册或提升路由，不会把 held 或 disabled 路由变成 `AVAILABLE`，不会选择默认模型，也不能证明任何模型已上线或已具备生产就绪状态。主机进程命令、资源发现、模型路径、凭据和部署准入都在控制器之外。该服务不会调用或配置语音计算端点。

## Verification

激活、复用、空闲卸载及关闭前必须读取目标的最新占用状态；跨目标切换还会检查原主机。新进程不能仅因内存中没有活动路由就假定 GPU 为空。不匹配或未知占用会返回 `RESIDENCY_UNVERIFIED`，并阻止包括关闭阶段在内的推测性清理。这是保守拒绝，不是自动接管或分布式互斥。部署 owner 仍负责 fencing 与权威状态调和。

每条路由的 `stageTimeoutsMs` 预算不可变，并参与权威与注册信息的一致性比较。冷模型启动可能比常规健康检查或作用域解析耗时更长；单纯增大全局超时会延迟无关故障。只有显式覆盖的阶段使用路由预算，包括回滚启动。默认值保持不变。

聚焦的运行时测试覆盖 FIFO 准入前的提供方分类、有序异步权威解析、精确作用域摘要校验、驱动工作前的路由身份拒绝、回执绑定、目标优先级、手动无回退行为、阶段顺序、完整流串行化、回滚、显式阶段超时、变更操作超时或清理未验证后的污染、审计权威失败、排队取消和空闲卸载。这些测试使用 fixture（测试前置数据）权威组件、路由和驱动；它们不能证明已部署主机驱动，也不能证明存在已上线或生产路由。

新增测试前置数据覆盖两个独立应用上下文观察已有驻留模型、卸载前占用变化、关闭检查失败、切换的两个目标及长启动预算隔离。真实 YAML Loader 组合驱动正式 agent loop，并将成功的助手输出和净化后的驻留状态失败固定在会话日志中。模型与主机均为确定性测试替身，不构成实时推理或全局控制器证据。

## Alternatives considered

**复用语音计算路由。** 拒绝，因为 STT 与 TTS 可用并不能证明 LLM 载荷、内存、运行时、作用域或准入已经就绪。共享控制器会组合互不相关的资源与治理职责。

**在进入 FIFO 前解析受治理路由。** 拒绝，因为异步解析会让更快的后续请求越过较早请求。只有粗粒度提供方分类发生在 FIFO 前，使普通外部提供方避开本地串行化。

**把切换放进每个模型适配器。** 拒绝，因为适配器无法跨提供方串行化一个稀缺槽位。共享 `llm/stream` 边界覆盖精确适配器迭代，同时不会让生命周期运行时成为模型选择权威。

**在用户选择模型时切换资源。** 拒绝，因为选择只记录意图，并且可能发生在另一项推理仍持有当前资源时。

**在控制器中硬编码路由、模型路径、进程或主机命令。** 拒绝，因为部署权威与主机专用驱动管理这些事实。共享运行时管理顺序、事务绑定、租约、截止时间和失败状态，而不管理基础设施发现、凭据或路由提升。

## Consequences

受治理本地模型推理由一个提供方无关的事务协调器管理，LLM 服务保留模型选择权威，外部权威组件保留分类、作用域、准入和审计所有权。普通外部提供方避开本地 FIFO。受管理请求要么达到由回执绑定的就绪状态，要么在可行时恢复已验证的先前状态；物理或审计状态不确定时，则把进程内槽位封闭为 `TAINTED`。

本地串行化协调同一 Host 进程内的调用者。受治理主机工作还必须获得部署签发、覆盖已注册可用候选目标的资源租约，并在空闲驻留期间保留。提供方拥有认证、准入、物理资源覆盖与 fencing；消费者负责有界获取、续租、到期和尽力释放。每个阶段携带当前授权，阶段回执绑定 fence。失去所有权会取消工作并阻止推测性清理；本地 `SETTLED` 释放从不授权物理资源重新分配。本包未实现生产签发方或服务端协议。

agent loop 冻结模型请求，因此资源取消在流准入后通过 `llm/dispatch-signal` 提供，而不是写入 `GenerateOptions.signal`。只有传输请求副本获得合并信号，调用者取消、消息身份、内容与预备适配器绑定均保留。真实 YAML 组合验证该集成可到达助手输出并释放本地锁；故障注入测试验证推理中续租丢失及两个上下文的资源仲裁。这些是 staging 模拟，不是已部署互斥或真实推理证据。
