# Agent Note: 子代理结算通知仅保留文本

Status: implemented

[English](2026-09-16-subagent-settlement-text-only.md) | 中文

## Problem

可继续子代理的终止输出可能包含推理、工具调用或其他非文本块。父代理的结算通知此前会转发所有终止块，导致内部推理和协议内容一并暴露，而不是只交付子代理的最终回答。

## Decision

结算通知按原顺序保留非空文本块，并省略所有非文本块。如果没有非空的最终文本，则告知父代理该子代理没有留下最终消息。子代理自身的持久会话和终止事件保持不变。

这是对上游提交 `29debb8b24` 行为的窄范围回移；不会把上游已变化的文件布局整体导入分叉较大的 GCP 分支。

## Consequences

父代理会收到简洁的公开结果，不包含隐藏推理、工具调用或媒体载荷。聚焦测试覆盖混合推理与文本，同时既有结算交付测试继续验证 exactly-once 和故障行为。
