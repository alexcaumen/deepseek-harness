# Agent Note: 侧栏显式目录交接

Status: implemented

[English](2026-09-04-sidebar-directory-handoff.md) | 中文

## Problem

侧栏把生成文件列表的 `Show in folder` 目标当作编辑器文件接管。读取端点拒绝目录，而宿主机的打开请求未被执行。

## Decision

固定依赖版本的补丁将具有显式目录语法的路径转发到原始宿主机方法。其他文件仍由编辑器接管。补丁同时更新发布源码及浏览器 bundle，锁文件绑定补丁摘要。

## Alternatives considered

**禁用编辑器拦截器。** 这会移除有用的文件打开流程。

**修改测试以接受编辑器页签。** 页签无法读取目录，也没有执行用户请求的文件夹操作。

**推断所有目录或新增元数据服务。** 受影响调用方已提供明确的点路径段目录目标。更广泛的类型判断和文件系统操作不属于本次修正。

## Consequences

没有显式目录语法的普通路径不新增类型推断。原始宿主机错误继续传播，卸载恢复原方法。自动测试不会打开操作系统文件夹或用户桌面。

## Verification

固定源码测试覆盖 Windows、POSIX、UNC、相对目录语法、文件接管、宿主机调用恰好一次、错误和卸载。未修改的完整应用生成文件场景点击按钮，通过模拟原生打开器观察真实 RPC，并检查单行布局。
